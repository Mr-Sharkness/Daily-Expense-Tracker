# 💰 Daily Expense Tracker

Простое и надежное консольное приложение на Python для ежедневного учета расходов. Проект позволяет пользователям фиксировать свои траты, просматривать историю операций, а также мгновенно получать базовую финансовую статистику (общую сумму и средний чек).

Главная особенность текущей версии — полная автономность: приложение автоматически сохраняет ваши данные при выходе и загружает их при старте, защищая базу данных от случайной порчи.

---

## ✨ Основной функционал / Features

* **💵 Добавление расходов (Add Expense):** Быстрый ввод потраченной суммы (поддерживаются как целые, так и дробные числа `float`).
* **📋 Просмотр истории (View All):** Вывод полного списка всех зафиксированных трат с удобной сквозной нумерацией элементов начиная с 1.
* **📊 Финансовая статистика (Analytics):** Автоматический расчет общей суммы затрат (Total) и среднего чека (Average).
* **💾 Автосохранение и автозагрузка:** Данные автоматически записываются при выходе и мгновенно подгружаются при запуске программы.
* **🧹 Полная очистка (Clear All):** Возможность мгновенно сбросить все записанные расходы одной командой как из оперативной памяти, так и из файла базы данных.
* **🛡️ Защита данных и обработка ошибок:** База данных хранится в зашифрованном бинарном формате (`.dat`). Программа устойчива к некорректному вводу (ValueError) и защищена от ручного изменения файлов пользователем.

---

## 🛠️ Стек технологий / Tech Stack

* **Язык:** Python 3.x
* **Модули управления данными:** `pickle` для сериализации данных в бинарный вид, `os` для проверки существования контрольных точек.
* **Структуры данных:** Динамические списки (`list`) для упорядоченного хранения истории транзакций.
* **Оптимизация:** Использование встроенных эффективных алгоритмов суммирования `sum()` и функции `enumerate()` для автоматического индексирования строк.

## 🚀 Как запустить / How to Run

Вы можете запустить проект как готовое скомпилированное приложение, так и напрямую через исходный код Python.

### Вариант 1: Запуск готового `.exe` (Рекомендуется для пользователей)
Вам **не нужно** устанавливать Python. 
1. Перейдите в раздел **[Releases](https://github.com/Mr-Sharkness/Daily-Expense-Tracker/releases)** на панели справа в этом репозитории.
2. Скачайте последнюю версию файла `Daily-Expense-Tracker.exe`.
3. Запустите скачанный файл двойным кликом.

*Примечание: При первом запуске Windows Defender может выдать предупреждение SmartScreen (так как у файла нет платной цифровой подписи разработчика). Нажмите "Подробнее" -> "Выполнить в любом случае".*

### Вариант 2: Запуск из исходного кода (Для разработчиков)
Если вы хотите изучить или изменить код, вам понадобится **Python 3.x**:

```bash
# Клонировать репозиторий
git clone https://github.com/Mr-Sharkness/Daily-Expense-Tracker.git

# Перейти в папку проекта
cd Daily-Expense-Tracker

# Запустить приложение
python "Daily Expense Tracker.py"
